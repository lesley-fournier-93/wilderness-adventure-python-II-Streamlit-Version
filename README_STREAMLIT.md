# Abenteuer in der Wildnis – Streamlit-Version

## Starten

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Dateien

- `streamlit_app.py` – neue moderne Streamlit-Oberfläche
- `wildnis_core.py` – bestehende Spiellogik
- `requirements.txt` – benötigtes Paket

Die Spiellogik bleibt getrennt von der Oberfläche. Dadurch kannst du später einfacher neue Features ergänzen.
